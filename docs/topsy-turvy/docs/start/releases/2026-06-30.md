## Language (Specification & Grammar)

:::danger[Breaking Changes]
**Static Typing:** The dynamic typing system introduced in v0.1.0 has been replaced and all values are statically-typed.  Any existing code using dynamic typing will no longer be valid Topsy Turvy code and will not parse or run.
:::

The following updates have been made to the language:

* Static Typing: Topsy Turvy is now statically-typed replacing existing dynamic type behaviour.  Please see the dedicated section for more details.

### Static Typing

* Removed Features:
    * In-place casts and the `IS HENCEFORTH` keyword.
    * Implicit variables and the `JUST SO` keyword.
    * Two-line conditional `SHOULD IT TRANSPIRE THAT` and switch `IN WHICH CAPACIT?` forms.
* Assignment & Casting:
    * `NAUGHT` is no longer treated as a type but a value only.
    * Types now have a default value and not `NAUGHT` as before.
    * Only `YARN` and `LITTLE LIST` variables can be assigned `NAUGHT`.
    * All elements of a `LITTLE LIST` must be of the same type.
    * `AS IT WERE` expression casts must be assigned to a variable to use the cast value.
    * `PRAY TELL` can only write to `YARN` variables.
    * Both the _true_ and _false_ values in a ternary expression must be of the same type.
* Truthiness:
    * Statements and expressions which require a `DECREE` now explicitly require a `DECREE` expression instead of truthiness; this includes all logical operators, conditionals, guards, asserts, loop conditions and the ternary expression.
* Functions:
    * All parameters must declare their types using `AS A <type>` in the function declaration.
    * If not void, a function must return a type at the end of its declaration using `TO FIND <type>`.
    * Use of a parameter in the function body must align with its type in the function declaration.
    * All arguments when calling a function using `SUMMON` must use values that match the function definition.
    * The type of the return value of a function must match the function declaration.
    * The `MY DUTY IS PREMATURELY DISCHARGED.` keyword is only valid in void functions.
* Exception Handling:
    * The thrown value from `A HIDEOUS CURSE UPON` must be a `YARN`.
    * In the try/catch `WITH THE GREATEST RESPECT` block, the `MODIFIED RAPTURE` block must declare a name for the caught value, even if unused.

## Toolchain

The following updates have been made to the _Operetta Toolchain_:

* Support for the latest language features.
* A new Type Checker component to perform static type checking between parsing and executing code.
* Enhanced parser to correctly assign source spans to AST nodes.
* Error diagnostics now appear in correct locations and not at the start of a block.

## VS Code Extension

The following updates have been made to the VS Code Extension:

* Support for the latest language features.

## Web Editor

:::warning[Experimental Features]
**Visual Editor:** While every effort has been made to ensure this new feature functions correctly, there may be unidentified issues and the functionality may change without warning in the future.
:::

The following updates have been made to the Web Editor:

* Support for the latest language features.
* Re-branded _Operetta Web Theatre_ in-line with the _Operetta Toolchain_.
* A Visual Editor, known as **The Stage**, for visual programming Topsy Turvy programmes and synchronising bidirectionally with the Code Editor.
