# 2025-06-24: Language v0.4.0 & Richer Dev Experience

|Specification|Grammar|Toolchain|VS Code Extension|Web Editor|
|-|-|-|-|-|
|0.4.0|0.3.0|0.3.0|0.3.0|0.3.0|

## Language (Specification & Grammar)

The following new features have been added to the language:

* Ternary Operator (`<true-value> SHOULD IT TRANSPIRE THAT <condition> OTHERWISE, <false-expression>`)
* Guard Clause (`YEOMAN <expression> OTHERWISE, <action> UNDER ORDERS.`)
* Assert Cluaw (`THE LAW IS <expression> THAT <error-message>`)
* Additional Primitive Types
    * Integers: 64-bit (`CHANCELLOR`), 16-bit (`PIRATE`), 8-bit (`SAUSAGE-ROLL`)
    * Unsigned Integers (`STANDING` for all integer types)
    * Floating-Point: 32-bit (`FOOT`)
    * Character (`STITCH`)
* `YARN` Support for Length (`RECKONING OF`) and Character Index Access (`VICTIM <index> ON`)
* Bitwise Operators (`CHORD OF`, `HARMONY OF`, `DISCORD OF`, `INVERSION`, `TRANSPOSITION UP`, `TRANSPOSITION DOWN`)

## Toolchain

The following new features have been added to the _Operetta Toolchain_:

* Support for all new language features.

### CLI

* `cadenza` (alias `interactive`) command to run the interactive REPL.
* `cue` (alias `preprocess`) subcommand in the `sorcerer` command graph to run the preprocessor for a file and output the result to standard output.
* `playbill` (alias `docs`) command to generate documentation for a file and output the result to standard output either as highlighted output or Markdown.

## VS Code Extension

The following new features have been added to the VS Code Extension:

* Support for all new language features.
* Commands to wrap the CLI across the Command Palette, Editor and Context Menus:
    * File Actions: Perform, Rehearse, Cue Processor, Generate Playbill Documentation, View AST Promptbook.
    * Creation Actions: Mount Project, Commission File.
    * Cadenza REPL.
* Command configuration in Settings, including Perform command-line arguments.
* Snippets for many common Topsy Turvy constructs.

## Web Editor

The following new features have been added to the Web Editor:

* Support for all new language features.
