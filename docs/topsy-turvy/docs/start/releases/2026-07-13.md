## Language (Specification & Grammar)

The following updates have been made to the language:

* Optional explicitly-sized bitwise shift operations (`TRANSPOSITION [UP|DOWN] <value> BY <shift-size>`).

## Toolchain

The following updates have been made to the _Operetta Toolchain_:

* Support for the latest language features.
* Support for native compilation, via .NET Native AOT, of core toolchain components to enable interoperability with other platforms.  Please see the _Toolchain (Native Contract)_ section below.
    * This includes the Lexer, Parser, AST, Runtime and Analysis System.

### Toolchain (Native Contract)

The Native Contract is a set of functions visible to native platforms exposing functionality of the Topsy Turvy toolchain, including:

* Create and destroy native sessions.
* Start and stop programme execution.
* Source code analysis, formatting and diagnostics.

It is currently used to power the Topsy Turvy execution and diagnostics in the iOS/iPadOS app (please see below).

### Toolchain (UtopIR)

:::info[Preview Features]
**UtopIR:** This intermediate representation of Topsy Turvy is in very early development supporting a very limited subset of the language and could change with no warning.  However, UtopIR does not affect established components of the existing toolchain.
:::

The following updates have been made to the UtopIR toolchain:

* Add support for floating-point arithmetic operations and casting.
* Add support for the `stitch` character type.
* Add bitwise operations for integers.

## VS Code Extension

The following updates have been made to the VS Code Extension:

* Support for the latest language features.
* Initial support for UtopIR, including syntax highlighting and file icons.

## Web Editor

The following updates have been made to the Web Editor:

* Support for the latest language features.
* **Bug Fixes:**
    * When calling a function from a SUMMON node it would call arguments from the function rather than SUMMON and drop the arguments altogether when generating code.
    * Switch blocks could not be added in the Viusal Editor.
    * When Switch blocks were being created in the Visual Editor they were being destroyed when generating code in the associated Tospy Turvy source.
        * Even though creating Switch blocks was not possible in the Visual Editor, this bug was identified when adding support.
    * Switch case bodies were being looked up by a hardcoded "Case N" label instead of the actual title and was therefore dropped.
    * Character literals were being converted to strings when generating code.

## iOS/iPadOS App

:::warning[Experimental Features]
**iOS/iPadOS App:** While every effort has been made to ensure this new app functions correctly, there may be unidentified issues and the functionality may change without warning in the future.
:::

This release introduces an iOS/iPadOS app, _Operetta Theatre_, to enable editing and running of Topsy Turvy code on the move and in offline environments.  In this initial release:

* Support for the latest language features.
* Supports editing of individual files and opening of a folder to work on multiple files at a time.
