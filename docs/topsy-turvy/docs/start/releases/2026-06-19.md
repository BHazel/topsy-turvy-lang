# 2026-06-19: Language v0.3.0

|Specification|Grammar|Toolchain|VS Code Extension|Web Editor|
|-|-|-|-|-|
|0.3.0|0.2.0|0.2.0|0.2.0|0.2.0|

## Language (Specification & Grammar)

The following new features have been added to the language:

* Arrays (`LITTLE LIST OF [<size>] <type>`, `VICTIM <index> ON`, `RECKONING OF <array>`)
* Command-Line Arguments (`THE PROPS`)
* Constants  (`CONSERVATIVE`, `[LIBERAL]`)
* Documentation Comments (Tags within block comments)
* Named Variable for Caught Exceptions (`MODIFIED RAPTURE, <name>`)
* Non-Mutating Type Casts as Expressions (`AS IT WERE <expression> AS A`)

## Toolchain

The following new features have been added to the _Operetta Toolchain_:

* Support for all new language features.
* Support for command-line arguments in the `perform` command.

## VS Code Extension

The following new features have been added to the VS Code Extension:

* Support for all new language features.
* Support for command-line arguments in the _Set Command-Line Arguments_ command.

## Web Editor

The following new features have been added to the Web Editor:

* Support for all new language features.
* Resizable code and terminal panes.
* Persistence of settings and text fields in Local Storage.
* Improved syntax highlighting of symbols.
