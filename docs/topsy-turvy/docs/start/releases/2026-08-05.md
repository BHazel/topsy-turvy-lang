## Language (Specification & Grammar)

:::danger[Breaking Changes]
**Function Overloading:** Declaring a function with the same signature as another is now an error rather than redefining the function.
:::

The following updates have been made to the language:

* Array declarations can now specify the size using a variable instead of just an integer literal (`PRAY WELCOME Array AS A LITTLE LIST OF ArraySize PEER`).
* Arrays can now be used as function parameters and return values.
    * **Only structural checking is complete; full type-checking is not yet implemented.**
* Function overloading is now supported, where declaring a function:
    * With exactly the same signature is now an error rather than silently redefining the original function.
    * Where, after widening, matches another signature is an error due to ambiguity.
    * That is identical to an external function is allowed and shadows the external function.

## Toolchain

The following updates have been made to the _Operetta Toolchain_:

* Support for the latest language features.
* Support for including external libraries, including the new **Standard Library (in preview)**, using the new **External Library SDK (in preview)**.

### CLI

* Function return types are now reported as a new column when running the `:armoury` command in the REPL.
* Support for including external libraries exposing functions using the new **External Library SDK (in preview)** for numerous commands (`perform`/`run`/`stage`, `rehearse`/`check`, `incantation`/`lsp`, `cadenza`/`repl` and `sorcerer`/`compile`) via a new `--admit`/`--include` flag.

### Toolchain (Native Contract)

* Support for calling functions from the Standard Library (in preview).

### Toolchain (UtopIR) _(Preview)_

:::info[Preview Features]
**UtopIR:** This intermediate representation of Topsy Turvy is in very early development supporting a substantial but incomplete subset of the language and could change with no warning.  However, UtopIR does not affect established components of the existing toolchain.
:::

* **UtopIR Language**
    * Strings
    * Arrays
    * Pointers
    * Namespaces
    * Function Declarations, including the `&Opera` entry-point function to wrap all logic itself not wrapped in a function.
    * Function Calling
* **.NET Emitter**
    * Support for including external libraries, including the new **Standard Library (in preview)**, using the new **External Library SDK (in preview)**.
* **Bug Fixes:**
    * Resolve issue in the .NET CIL emitter where non-first branches in Switch blocks were not receiving host-injected services.

## Standard Library _(Preview)_

:::info[Preview Features]
**Standard Library:** This is currently in very early development supporting only a couple of preview functions at present and could therefore change with no warning.
:::

The Standard Library is a built-in library of common functions available to all Topsy Turvy programmes.  In this initial preview the following functions are included:

* Preview functions underpinning the `BEHOLD` and `PRAY TELL` keywords.

## External Library SDK _(Preview)_

:::info[Preview Features]
**External Library SDK:** This is currently in very early development and could change without warning.
:::

The External Library SDK is a collection of types to enable external .NET methods to be exposed to Topsy Turvy programmes to allow them to be called via the `SUMMON` keyword.  In this initial release the following is supported:

* Attributes to bind a function and its parameters.
* Ability to interact with standard input and output.
