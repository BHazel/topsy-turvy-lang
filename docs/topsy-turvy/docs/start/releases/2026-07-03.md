# 2026-07-03: Language v0.6.0 & UtopIR Preview 1

|Specification|Grammar|Toolchain|Toolchain (UtopIR)|VS Code Extension|Web Editor|

:::danger[Breaking Changes]
This release introduces breaking changes affeecting all components.
:::

:::info[Preview Features]
This release introduces preview features which are incomplete and in early development.

## Language (Specification & Grammar)

:::danger[Breaking Changes]
**Ascending Loop Variable:** Ascending loops as introduced in v0.1.0 no longer reset the loop variable to 0 when entering a loop but instead use its value as-is.
**`EITHER x OR y` Operator:** This was incorrectly implemented since v0.1.0 with an `AND` keyword, which has been fixed and now no longer works.
:::

The following updates have been made to the language:

* **New Features:**
    * Ascending loops no longer reset the loop variable to 0 on entering the loop.  The variable value is used as-is.
    * Steps in ascending and descending loops with `BY <value>` (`BY A LEGAL FICTION [ASCENDING|DESCENDING] <var> BY <value> UNTIL <condition>`)
    * Programme-level return (`PEER`) statement (`AND SO I FIND <value>`)
* **Bug Fixes:**
    * `EITHER x OR y` logical OR operator was incorrectly implemented as `EITHER x AND y` and has now been fixed.
    * The lexer now correctly stores a `CHANCELLOR` as a `long` rather than `int` thus preventing data loss.

## Toolchain

:::danger[Breaking Changes]
**CLI Sorcerer Command Group:** This has been repurposed into a single command, with the alias `compile`.  Please see the **CLI** section below for more information.
:::

The following updates have been made to the _Operetta Toolchain_:

* Support for the latest language features.

### CLI

The `sorcerer`/`dev` command group has been repurposed into a single command to expose toolchain actions and add support for the new, currently in preview, compilation infrastructure and UtopIR.

* **Removed Features:**
    * The `dev` alias.
* **Existing Subcommands:**
    * `incantation`/`lsp` has been moved into its own root-level command, executable using `operetta incantation` or `operetta lsp`.
    *  `ast`/`promptbook` and `cue`/`preprocess` have been folded into the new repurposed command (please see below).
* **New Features:**
    * A new `compile` alias.
    * A `--pour`/`--emit` flag which outputs a specified code format to STDOUT:
        * Preprocessed Topsy Turvy, replacing the former `cue`/`preprocess` subcommand, using flag `--pour [preprocess|p|cue|c]`.
        * AST Promptbook, replacing the former `ast`/`promptbook` subcommand, using flag `--pour [ast|a|promptbook|b]`.
        * UtopIR, using flag `--pour [utopir|u]`.
        * UtopIR AST Promptbook, using flag `--pour [utopir-ast|s]`.
        * .NET CIL, using flag `--pour [dotnet-cil|d]`.
    * A `--philtre`/`--target` flag which builds a binary for a specified platform:
        * .NET Assembly, using flag `--philtre dotnet`.
    * An `--output` flag to control the output location of the `--philtre`/`--target` flag.
    * A `--config` flag to control both flags with format or platform specific settings.

### Toolchain (UtopIR)

:::info[Preview Features]
**UtopIR:** This intermediate representation of Topsy Turvy is in very early development supporting a very limited subset of the language and could change with no warning.  However, UtopIR does not affect established components of the existing toolchain.
:::

UtopIR is an intermediate representation of Topsy Turvy combining the Gilbert & Sullivan theme of Topsy Turvy and applying it to lower level virtual register and stack operations.  This language will provide a simpler pathway for interoperability between Topsy Turvy and other platforms.  The UtopIR related components of the toolchain introduce compiler infrastructure to support compiling binaries to other platforms.

The following updates have been made in this initial release of UtopIR:

* **Language:**
    * Variable declaration and assignment operation instructions.
    * Arithmetic operation instructions.
    * Cast operation instruction.
    * Stack operation instructions.
* **Toolchain:**
    * Lexer and Parser for UtopIR to generate an AST.
    * Code Generator to write UtopIR code from an AST.
    * Transformer for a Topsy Turvy AST to UtopIR AST.
    * Emitters for .NET CIL code and binaries.
