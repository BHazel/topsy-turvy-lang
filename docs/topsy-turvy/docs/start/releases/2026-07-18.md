## Language (Specification & Grammar)

The following updates have been made to the language:

* **Namespaces**
    * File-level namespaces can be declared using `TOWN <namespace> [WITH DISTRICT <subnamespace> ...]` or shorthand `TOWN <namespace>[*<subnamespace> ...]` statements at the top of a source file.
    * When importing a file the namespace can be opened using `PRAY RECOGNISE <namespace> [WITH DISTRICT <subnamespace> ...]` or shorthand `PRAY RECOGNISE <namespace>[*<subnamespace> ...]` statements at the top of a source file.
    * Fully-qualified function names include the namespace path, delineated with the `*` character; once a namespace is opened the fully-qualified name is not required.
* **Pointers**
    * Pointer types can be declared using `GALLERY PICTURE OF <type>` declarations, `NAUGHT` by default if unassigned.
    * Pointers can be assigned to a variable of a matching type using `GALLERY PICTURE TO <variable>`.
    * Deferencing a pointer is done using `VIEW FROM <pointer>`, both for reading and writing.  However, `YARN` strings do not support writing of individual characters.
    * Pointer arithmetic is supported for `LITTLE LIST` arrays and `YARN` strings using `SUM OF` and `DIFF OF`.

### Toolchain (UtopIR)

:::info[Preview Features]
**UtopIR:** This intermediate representation of Topsy Turvy is in very early development supporting a very limited subset of the language and could change with no warning.  However, UtopIR does not affect established components of the existing toolchain.
:::

The following updates have been made to the UtopIR toolchain:

* Conditional and logical operators.
* Labels and branching.
* Support for If/Else-If/Else blocks, ternary clauses, Switch blocks and Loops.
